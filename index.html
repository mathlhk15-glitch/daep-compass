자료와 해석의 차이

자료 기준: 2026학년도 입시결과까지 수록. 2027학년도 결과는 미포함입니다.

기초자료: 2021~2025학년도 대교협 발표 수시 입시결과 이투스 통합 편집본, 2026학년도 대학어디가 수시입결 취합자료(남악고 김현석 편집본)를 바탕으로 재편집. 출처의 직접 공인·재배포 허용을 의미하지 않습니다. 과거 발표자료와 대학별 공식 모집요강은 별개입니다. 프로그램은 합격 확률을 산출하지 않으며 ‘과거 컷과의 상대적 위치’만 표시합니다.

등급 50%·70% 컷은 실제 최저합격자 등급이 아닙니다. 충원순위도 모집인원이 없거나 기준이 다른 경우 계산하지 않습니다. 과거 모집단위·전형명이 바뀐 경우 동일 집단으로 연결되지 않을 수 있습니다.

5등급제 사용 안내

5등급제 평균등급은 경기·부산·광주 통계 대응표를 이용하여 추정 9등급제 참고값으로 표시할 수 있습니다. 이 통계적 추정값은 공식 환산등급과 다르며, 과거 9등급제 입결과의 숫자상 차이만 탐색합니다. 2028학년도 지원 전략 수립에는 해당 연도 모집요강, 산출 방법, 수능 최저 및 계열별 과목 기준의 추가 데이터가 필요합니다.

데이터 확인 필요

원자료 점검사항이 있는 데이터는 상세 화면에 표시됩니다. 2021~2025 일부 기록은 X가 붙은 원문 문자열 또는 결측값이 있고, 2026 이전 자료의 지역·소계열 분류는 완비되어 있지 않습니다. 2021~2025 지역값 일부는 2026 대학명과 정확히 일치할 경우 참고 지역으로 보완되며, 미확인 대학은 지역 검색에서 제외됩니다.

경일고·경일여고 선배 사례

「입시자료 선택」에서 선배 사례 또는 비교를 고르면 2024~2026학년도 경일고·경일여고 수시 지원 기록을 원서 한 건씩 보여 줍니다(연도·대학·모집단위·전형·전교과/국영수사과 내신·최초합격/충원합격/불합격, 예비순위, 최저 미충족 등). 이름·학번은 원래 없고, 한 학생의 여러 원서를 연결하는 정보와 수능·과목별 점수는 넣지 않았으며, 내신은 소수 첫째 자리까지 표시합니다. 선배 내신은 9등급제이며, 5등급제 학생은 통계적 추정 9등급 값으로 비교합니다. 과거 기록이며 합격 가능성 예측이 아닙니다. 교내 상담용 자료이므로 학교 승인 없이 공개 인터넷 주소에 올리지 마세요.

실행 및 배포 안내

별도 웹서버의 HTTP(S) 주소로 접속해 사용할 수 있습니다. 원자료의 공개 재배포 권한이 확인되기 전에는 공개 GitHub Pages에 데이터 파일을 올리지 마세요. 승인된 내부 서버 또는 접근제한 환경에서 시범 운영하세요. HTML 파일을 더블클릭(file://)하면 브라우저의 로컬 파일 접근 제한으로 데이터가 불러와지지 않습니다. index.html과 data 폴더를 같은 웹서버 경로에 배치해 접속하세요.
