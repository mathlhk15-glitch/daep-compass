# 대입 나침반 학부모용 v2.6 — 환산등급 비교 강화

## 이번 변경
- 자녀의 5등급제 평균을 입력하면 상단에 추정 9등급제 참고값을 크게 표시합니다.
- 검색 결과 위쪽에 추정 9등급 값을 반복 표시하여 스크롤 중에도 비교 기준을 놓치지 않게 했습니다.
- **학생부교과 카드**에서 내 아이 추정 9등급과 대학의 과거 70% 컷을 나란히 표시합니다. 카드의 강조는 과거 입결과의 숫자상 비교일 뿐 합격 가능 판정이 아닙니다.
- 종합·논술·실기 등은 내신 평균만으로 지원 가능성을 판단하지 않습니다.
- 9등급제 직접 입력 및 성적 없이 탐색도 가능합니다.

## 5등급 변환의 근거
경기·부산·광주 대응표 원자료: https://github.com/kangseok-hub/converter/blob/main/src/data/conversionData.ts
변환 알고리즘: https://github.com/kangseok-hub/converter/blob/main/src/lib/admissionUtils.ts
웹사이트: https://kangseok-hub.github.io/converter/
대응표 구간 선형 보간, '3지역 평균' 선택 시 지역별 결과의 산술평균을 사용합니다. **공식 등급 환산 방식이 아닌 통계적 추정**입니다.

## 사용 방법
`index.html`, `app.js`, `conversion.js`, `data/`를 같은 웹 서버 경로에 올려 실행합니다. HTML 파일 단독 더블클릭은 fetch가 차단될 수 있습니다.
