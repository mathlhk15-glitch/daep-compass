# 대입 나침반 v4.9 — 통합 검색 화면 (전국 입결 + 우리 학교 선배 사례)

2021~2026 전국 수시 입시결과와 선택형 학생부 PDF 성적 분석을 제공하는 참고용 웹앱입니다. 합격 가능성 판정 도구가 아닙니다.

## v4.9 변경 사항
### 1. 화면 구조 오류 수정 (중요)
- 대학 찾기 화면의 연도 선택 영역에 `</div>`가 하나 남아 있어, 브라우저가 대학 찾기 탭을 일찍 닫아 버리던 문제를 고쳤습니다.
  - 증상: 어느 탭을 눌러도 전국 검색 결과 카드가 화면 위쪽에 계속 보이고, 다른 탭 내용이 그 아래로 밀려 보이지 않음 (v3.7 무렵부터)
- 이 오류를 메우려고 넣었던 학교 사례 화면 폭 보정 CSS를 지웠습니다.

### 2. 통합 검색: 「입시자료 선택」
- 대학 찾기 화면에서 자료 출처만 바꿔 봅니다.
  - **전국 대학 입시결과** (기본): 기존 전국 입결 탐색
  - **경일고·경일여고 선배 사례**: 학교 집계만 표시
  - **전국 입결 + 우리 학교 사례 비교**: 전국 카드와 학교 집계를 함께 표시
- 성적, 대학·학과 검색어, 관심 전형, 분야 선택은 **한 번만 입력하면 세 방식에 모두 적용**됩니다.
  - 5등급제 성적은 선택한 환산 기준의 추정 9등급 값으로 비교합니다.
  - 성적 없이 둘러보기를 고르면 전체 성적대를 보여 줍니다.
- 학교 사례 전용 설정: 학교 복수 선택(창원경일고·경일여고), 비슷한 성적 검색 범위(±0.1~3.0), 선배 사례 연도(2024~2026 전체 / 위 입시결과 연도와 같게)
- 별도의 「경일고·경일여고 사례」 탭은 없앴습니다. 메뉴는 5개입니다.

### 3. 전국 카드에 「🏫 우리 학교 선배 사례 보기」
- 학교 집계 CSV를 불러온 경우에만 표시합니다.
  - 전국 모드: 접힌 버튼
  - 비교 모드: 펼친 상태
- 연결 기준: 같은 대학(본교·분교 구분), 같은 전형, (CSV에 학과가 있으면) 같은 학과, 비슷한 성적 구간
- CSV를 불러오면 자동으로 비교 모드로 전환합니다.

## 학교 집계 CSV
- 헤더: `학교,연도,등급구간시작,등급구간끝,대학,학과,전형,지원구간,합격정보,독립학생수`
- 학교명: 창원경일고/경일고, 경일여고/창원경일여고
- 전형: 교과/종합/논술/실기·기타로 자동 정리
- 엑셀은 「CSV UTF-8」 저장을 권장합니다. 일반 CSV(CP949)도 인식합니다.
- 파일은 브라우저 안에서만 처리하며 서버로 보내지 않습니다. 새로고침하면 사라집니다.
- **원서 10건은 서로 다른 학생 10명이 아닙니다.** 공개 전에 다음이 필요합니다.
  - 학교 승인
  - 서로 다른 학생 수 검증
  - 소수 집단 재식별 위험 검토
