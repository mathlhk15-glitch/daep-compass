# 대입 나침반 v4.7 — 재검수 및 공개 안전성 개선

2021~2026 대학 입시결과와 선택형 학교생활기록부 PDF 성적 분석을 제공하는 참고용 웹앱입니다.

## 이번 수정 (v4.7)
- CP949(한글 Windows 엑셀 CSV)와 UTF-8 모두 지원, CSV 따옴표 구조 및 줄 번호 검사 강화.
- 학교 사례 CSV의 학교·전형 약칭 연결, 대학명 검색, 겹침 구간 검색과 일부 겹침 경고. 집계 구간 일부만 겹칠 경우 해당 범위 밖의 선배도 포함될 수 있습니다.
- 학교 사례 CSV 구조·연도·등급구간·정수 학생 수 기본 검사와 오류 행 사유 표시. 브라우저 검사는 학교 승인, 실제 서로 다른 학생 수, 개인정보 재식별 위험을 보증하지 않습니다.
- 잘못된 CSV 업로드 시 기존 자료 유지 및 현재 표시 자료명 고지. 같은 파일 재선택 가능. 결과 100개씩 추가 표시.
- 대학 찾기의 비교 등급을 학교 사례에 가져오는 버튼. 5등급제는 선택 중인 통계적 환산 기준 이용.
- 본교 캠퍼스 표기가 있는 대학군 분류/비교 보완, 상세 비교표 이중 이스케이프 수정, 직접 성적 입력 시 출처 안내 갱신.

## 배포 전 필수 사항
- 이 배포본에는 개별 선배 지원 이력이나 세부 합불 집계가 포함되어 있지 않습니다. 학교 사례는 검토를 마친 CSV를 선택해야만 작동합니다.
- CSV 헤더: 학교,연도,등급구간시작,등급구간끝,대학,학과,전형,지원구간,합격정보,독립학생수.
- CSV 학교명: 창원경일고/경일고, 경일여고/창원경일여고 지원. 전형은 교과/종합/논술/실기·기타로 정규화합니다.
- **원서 10건이 독립학생 10명을 의미하지 않습니다.** 집계를 공개하기 전 학교의 적법한 공개 승인, 서로 다른 학생 수의 검증, 소수집단 재식별 위험 평가가 필요합니다.
- 이번 ZIP은 루트에 index.html 등 파일이 바로 있는 구조입니다. CSV는 Excel의 **CSV UTF-8** 저장을 권장합니다.
- GitHub Pages에 이전에 배포한 `data/school-explore.json`, `data/school-summary.json`은 새 ZIP 업로드로 지워지지 않습니다. 공개 저장소의 현재 파일과 과거 커밋을 점검해 삭제/기록정리 또는 안전한 새 저장소로 이전하세요.
- 전국 대학 입결 원자료의 재배포 권한도 별도 확인하세요.

## 한계
- 검색결과는 과거 성적의 대략적인 비교이며 합격 가능성 판정이 아닙니다.
- 집계 등급구간과 사용자가 입력한 검색구간이 겹치면 표시합니다. 집계구간 전체가 검색범위 안에 있는 것은 아닐 수 있습니다.
- 실제 브라우저 및 각 학교 양식의 PDF 업로드 전체 과정은 추가 회귀 테스트가 필요합니다.

## v4.7 추가 점검
- 캠퍼스 지정 검색은 해당 캠퍼스만, 캠퍼스 미지정 검색은 본교 및 캠퍼스를 별도 카드로 표시합니다. 자료의 캠퍼스 정보가 없는 경우 구분할 수 없습니다.
- 학교 사례 성적 입력을 수정하면 가져오기 안내를 수동 수정 상태로 갱신합니다.
- 실제 학교생활기록부 PDF 전체 인식 및 공개 승인 검증은 별도 검증이 필요합니다.
