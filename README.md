# 대입 나침반 v2.3 | 2021~2026 수시 입결 탐색

## 설치
1. 압축 해제 후 `index.html`, `app.js`, `data/` 폴더를 **동일한 GitHub 저장소 최상위**에 업로드합니다.
2. 공개 재배포 허용 범위와 권한을 확인한 뒤에만 GitHub Pages에 공개 배포합니다. 허용 전에는 접근 제한된 교내 서버 등에서 시험합니다.
3. 운영 중인 HTTP(S) 서버 주소로 접속합니다. 별도 서버/설치/회원가입은 필요하지 않습니다.
4. 파일을 로컬에서 직접 열면 보안정책상 `fetch`가 차단될 수 있으므로 웹 서버에서 확인하세요. 로컬 시험 예: `python -m http.server 8000` 실행 후 http://localhost:8000 접속.

## 포함 데이터
사용자가 제공한 `2021-2026_수시입결_최종검수_서식개선본.xlsx`의 `6년통합` 시트 108,596행. 2026년 14,385행 포함. 원본에서 결측 처리된 점수는 그대로 유지. 일부 대학/학과/연도 조합이 한 해에 여러 전형으로 존재합니다.

## 기능
- 9등급제: 평균등급 대 과거 70% 컷 **상대적 위치만** 표시. 합격률·안정/적정/도전 확정 표현 사용하지 않음
- 5등급제: 성적 비교 없음 (과거 9등급제와 직접 비교 금지)
- 2021~2026 연도별 검색, 대학·모집단위·계열 키워드 검색, 지역/전형 필터, 정렬
- 관심목록 브라우저 저장, 최대 6개 후보 선택 및 인쇄/PDF 저장
- 상세 입결: 6개년 등급 70% 컷 추이, 비교 가능한 연도별 수치, 원자료 점검사항
- 선택 연도의 소계열 정보가 비어 있을 때 학과명 키워드로 관심 분야 검색

## 자료 사용상 주의
- 모집인원 0, 원자료 오류, 대학 명칭/전형 변경 가능성은 공식 입학처로 확인
- 대학별 환산점수 만점/반영 기준 불일치. 학교 간 직접 비교 금지
- 2021~2025에는 지역·계열·소계열 결측이 많아 지역 필터 사용 시 결과에서 빠질 수 있음
- 학종은 정성평가가 포함되므로 등급만으로 지원 가능 여부 단정 금지
- 관심 목록과 입력한 등급은 브라우저 내부에서만 처리, 별도 서버 저장 없음

## 파일
- `index.html`: UI
- `app.js`: 검색/분석/차트/저장/인쇄 로직
- `data/2021.json` ... `data/2026.json`: 검색 데이터
- `data/meta.json`: 건수 및 필드 목록

## v2 개선 사항
- 연도·원본 행 위치 기반 고유 ID 적용(단, 기존 v1 브라우저 저장 목록은 구조가 달라 v2에서 새로 저장 권장)
- 다른 전형을 임의로 연결하던 연도별 입결 추이 로직 제거. 정규화된 전형명이 같은 경우에만 연결하고 선택 기록을 우선 사용
- 전 연도 점검 플래그: 컷 역전, 1~9 밖의 등급, 비수치 모집·경쟁·충원, 모집인원 0, 100 초과 경쟁률
- 2026년에 동일한 이름으로 수록된 대학은 과거 연도 지역 검색을 보조(전체 지역 복구 아님)
- 70% 컷 있는 항목만, 모집인원 0 제외 필터, 학종·논술 등급 해석 구분
- 수시 후보 순서 변경, 메모, 로컬 JSON 백업·가져오기, 인쇄 대비 강화

## 주의 및 검수
- 파일을 직접 더블클릭하는 대신 GitHub Pages 등의 HTTP(S) 웹서버에 배포해야 데이터 fetch가 정상 작동합니다.
- 대학 명칭이 같아도 대학·캠퍼스 구분은 임의 병합하지 않으며, 전형명 유사성은 동일한 전형이라는 보증이 아닙니다.
- 2021년 입결 등급은 결측이 많으므로 6년치 데이터가 전부 존재한다고 가정하지 마세요.
- 원자료 제공 기관의 공개 재배포 조건은 별도 확인이 필요합니다.


## v2.1 변경 및 검증 안내
- 전형 정규화: `학생부` 단위를 먼저 제거. 서로 다른 모집 자격을 섞지 않도록 엄격하게 연결하며, 일치 불확실 시 연결하지 않습니다. 빈 전형 키는 `기본`으로 분류하나 이것만으로 동일 전형임을 보증하지 않습니다.
- 확정적인 문자열 오타 교정, 줄바꿈/공백 정리 및 서울과기대 표기 통일. 원본 엑셀은 수정하지 않았으며 앱용 JSON만 정제했습니다.
- 6개년 상세표에 미연결 연도 표시, 같은 연도 후보 중복 경고, 브라우저 저장 경고 1회 제한, 백업 가져오기 덮어쓰기 확인.
- 브라우저 저장키 V2로 교체. 이전 저장 항목은 가능하면 이전하되 동일한 기록을 식별하지 못하는 경우는 재등록이 필요할 수 있습니다.
- 추가 데이터 검증이 필요한 대학별 입결과 전형 동일성은 원자료를 확인해야 합니다. 모든 대학의 모집요강을 대조한 것은 아닙니다.
- **공개 전 자료 재배포 허용 조건은 제공 기관에 확인해야 합니다.**
- 실제 수시 지원에는 모집요강·수능 최저·대학별 교과 반영방식을 별도로 확인하세요.


## v2.2 변경사항
- 1회성 V1→V2 관심목록 이전 완료 플래그를 도입하여, 빈 목록이 새로고침 후 되살아나는 문제를 방지했습니다.
- 전형명 양끝의 교과/종합/논술 표기를 모두 제거하는 보수적 표준키를 사용합니다. 지원자격이 다른 전형은 자동 병합하지 않습니다.
- 6년 추이에 50% 컷/70% 컷/경쟁률 전환을 추가했습니다. 이 결과는 동일 모집단위·전형명의 *문자열 비교*일 뿐 공식 동일 전형 인증이 아닙니다.
- 6장 후보의 동일 대학, 전형 편중, 모집인원 0 및 컷 결측 여부를 경고합니다. 중복지원 가능 여부는 입학처에서 확인해야 합니다.
- 지역 필터로 제외된 지역 미확인 데이터 건수를 검색 결과에 안내합니다.
- 5등급제는 과거 컷 열람만 허용하고 수치 비교 및 합격 예측을 금지합니다.
- 원자료 숫자는 교정하지 않았습니다. 범위 밖 등급, 컷 역전, 2026년 일부 대학 미수록 및 이상 경쟁률은 별도 공식 자료 확인이 필요합니다.
- 원자료 제공기관의 재배포 조건을 확인하기 전에는 학교 내부 용도로만 사용하세요.


## v2.3 변경사항 및 제한
- 전형명 정규화 완료 뒤의 별칭키를 사용하도록 수정(예: `성적우수자` → `성적`, `우수` → `우수자`). 동일 전형이라는 공식 확인을 대체하지 않습니다.
- 지역 미확인 제외 건수는 현재 검색어·분야·전형·70% 컷 유무·모집인원 0 제외 조건을 반영합니다.
- 6장 후보 맨 앞 3개를 나란히 비교하는 표를 추가했습니다. 정확히 같은 학년도·산출방식이 아니면 단순 비교로만 활용합니다.
- 탭과 패널 연결 접근성 속성, 모달 키보드 포커스 순환, 백업 입력 포커스 표시를 보완했습니다.
- 앱용 데이터 108,596건과 원자료 숫자는 수정하지 않았습니다. 범위 밖 등급·컷 역전·일부 대학 미수록 등은 공식 확인 필요합니다.
- 데이터 출처: 2021~2025 대교협 발표 수시입시결과 이투스 통합 편집본 및 2026 대학어디가 수시입결 남악고 김현석 편집 취합본을 바탕으로 한 2차 가공자료. 게시 전에 각 원자료의 재배포 이용조건을 확인해야 합니다.
- **공개 GitHub Pages 업로드는 재배포 허용이 확인된 경우에만 진행하세요.** 사이트 설명과 README에 이 조건을 동일하게 반영했습니다.
