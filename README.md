# 대입 나침반 v5.0 — 전국 입결 + 경일고·경일여고 선배 사례 통합판

2021~2026 전국 수시 입시결과, 2024~2026 경일고·경일여고 선배 집계, 학생부 PDF 성적 분석을 한 화면에서 비교하는 참고용 웹앱입니다. 합격 가능성 판정 도구가 아닙니다.

## 배포본 두 가지
| 배포본 | 학교 선배 집계 | 용도 |
|---|---|---|
| **교내용** | `data/school-cases.csv` 포함 → 선배 사례가 바로 표시됨 | 교내 상담·학교 승인 후 배포 |
| **공개용** | 미포함 → 집계 CSV를 직접 불러와야 표시됨 | 공개 GitHub Pages |

두 배포본의 코드는 같습니다. 교내용은 index.html의 `<meta name="compass-school-data" content="on">` 표시가 있을 때만 `data/school-cases.csv`를 자동으로 읽습니다. 공개용은 이 파일을 찾지 않습니다.

## v5.0 변경 사항
### 1. 학교 선배 집계 내장 (교내용)
- 원자료: 2024~2026 경일고·경일여고 수시 합불 엑셀 (원서 4,288건, 학생 783명)
- 학생 구분: 졸업연도·교과별 내신·수능 성적 조합으로 서로 다른 학생을 셉니다. 이 조합은 집계 중에만 쓰고 결과 파일에는 넣지 않습니다.
- 공개 기준: **서로 다른 학생 10명 이상**인 묶음만 공개합니다.
  - 인원·원서·합격 수는 5단위 구간으로 표시합니다.
  - 5건 미만은 「5건 미만」으로만 적습니다(0 포함).
- 집계 단위 4가지: 학과·등급구간 / 학과 전체 / 대학·등급구간 / 대학 전체
  - 등급구간은 9등급제 전교과 평균의 정수 구간입니다.
  - 「전체 성적대」 행의 등급구간은 지원 학생 대부분(10~90%)이 속한 범위를 정수 단위로 넓힌 값입니다.
- **두 학교 합산 행:** 같은 묶음에서 두 학교 모두 기준에 못 미칠 때만 만듭니다. 한 학교 수치를 빼서 다른 학교의 소수 집단을 역산하는 일을 막기 위해서입니다. 두 학교를 모두 선택해야 보입니다.
- 결과: 263행 (학교별 174행 + 합산 89행)
- 원자료와 별도로 다시 세어 검증했습니다.
  - 학생 10명 미만 행: 0
  - 합산 행과 학교별 행의 중복: 0
  - 개인 내신 수치 노출: 0

### 2. 통합 검색 보완
- 성적이 있으면 등급구간 집계를 먼저 보여 줍니다. 같은 대학·학과·전형에 등급구간 집계가 없을 때만 전체 성적대 집계로 보충합니다.
- 성적 없이 둘러보기를 고르면 전체 성적대 집계만 보여 줍니다(중복 제거).
- 적용 조건(비교 등급 범위, 연도, 학교, 검색어)을 결과 위에 칩으로 표시합니다.
- **학과 매칭을 엄격하게 바꿨습니다.** 핵심어가 완전히 같을 때만 연결합니다.
  - 물리학과 ↔ 물리치료학과, 경영학과 ↔ 경영정보학과처럼 잘못 연결되던 문제를 해결했습니다.
- 분교 구분은 전국 자료가 구분하는 캠퍼스만 따릅니다.
  - 세종·미래·ERICA·WISE·글로컬·안성·천안·삼척·죽전 등
  - 칠암·통영처럼 전국 자료가 구분하지 않는 캠퍼스는 본교에 연결합니다.
- 전국 카드의 「🏫 우리 학교 선배 사례 보기」
  - 학과 단위 집계가 있으면 그것을 보여 주고, 없으면 대학 단위 집계를 보여 줍니다.
  - 전국 모드에서는 접혀 있고, 비교 모드에서는 펼쳐집니다.
- 공개용 화면: 자료가 없을 때 「CSV 불러오기」와 「CSV 양식 내려받기」 버튼이 바로 보입니다.
- 선배 사례는 24건씩 나눠 표시합니다(휴대폰 대응).
- 연도 표기 `2024~2026` 형식과 선택 열 「집계단위」를 인식합니다.

### v4.9에서 이어지는 수정
- 남는 `</div>` 때문에 다른 탭에도 전국 카드가 보이던 구조 오류를 고쳤습니다.
- 학교 사례 탭을 대학 찾기 화면에 합쳤습니다. 「입시자료 선택」 버튼은 3가지입니다.
  - 전국 대학 입시결과
  - 경일고·경일여고 선배 사례
  - 전국 입결 + 우리 학교 사례 비교

## 한계
- 개인정보 보호 기준 때문에 학과 단위 공개는 적습니다(학교별 11행, 합산 14행). 대부분 대학 단위 집계입니다.
- 논술·실기 집계 일부(22행)는 전국 입결에 같은 대학·전형 기록이 없어 카드에 연결되지 않습니다. 선배 사례 화면에서는 보입니다.
- 마산대·DGIST·UNIST 집계는 전국 자료에 해당 대학이 없어 선배 사례 화면에서만 보입니다.
- 선배 집계의 등급은 원자료의 「전교과내신」 기준입니다. 대학별 환산 등급과 다를 수 있습니다.
