# 대입 나침반 v3.7

2021~2026학년도 입시결과 기준 연도를 체크박스로 복수 선택할 수 있습니다. 초기값은 2026학년도입니다.

기존 나의 6장 후보 목록은 삭제하지 않고 같은 브라우저 저장소에서 그대로 이어받으며 최대 10개까지 담을 수 있습니다. 해당 목록은 원서 접수 계획이 아니라 진학 탐색용 비교표입니다.

# 대입 나침반 v3.6 — 학부모 탐색 + 교사 성적 분석(시범)

- 2021~2026 입시결과 데이터 108,596건 유지. 대학별 공식 환산·합격판정 도구가 아닙니다.
- 학생부 PDF 자동 분석은 **시범 기능**입니다. 원본 표 형식에 따라 누락/오인식이 가능하므로 원본 행 전체를 대조하세요. 실제 NEIS 학생부 PDF 표본 검증은 아직 완료되지 않았습니다.
- 계산에 포함되는 학기는 1-1, 1-2, 2-1, 2-2, 3-1이며 3-2는 항상 제외합니다. 석차등급이 있는 과목만 학점 가중평균에 사용합니다.
- 입력 PDF는 브라우저 내에서 읽고 학생부 데이터를 서버로 전송하지 않지만, PDF 해석용 라이브러리는 외부 CDN 로드가 필요합니다.
- 스캔 PDF는 OCR 미지원입니다. 자동 인식 보류 목록에 나온 항목과 추출되지 않은 원본 과목은 직접 대조하고 입력해야 합니다.
- 공개 배포 전 입시 원자료 저작권/재배포 권한을 확인하세요.

## v3.4 변경
- NEIS 텍스트 PDF의 머리글 및 x좌표를 고려한 PDF 추출/보류행 표시와 페이지 번호 기록.
- PDF.js 4.10.38 보안 수정 버전(legacy UMD인 3.x 대신 모듈)으로 교체, `isEvalSupported:false` 설정. 외부 CDN 연결 불가 시 수동 입력 가능.
- 자동 교과군 추정 + 수동 교과군 수정, 반영 제외, 학점 기준 0 초과 ~ 30 이하 통일.
- 새 업로드/초기화 작업 토큰, 원본 표시, 즉시 검토 해제, 실패 시 기존 기록 유지.
- 검토 상태/등급 체계/기간이 포함된 인쇄 표시, 검토 평균의 대학 검색 적용 버튼.
- 교과 가까운 입결 필터 문구 수정, 2021/논술 원자료 한계 표시, 데이터 이상기록 비교 강조 보류, 정렬 조정.

※ 실제 학생부 예시 2~3건으로 추출 건수·학점·등급을 검증하지 않은 상태입니다. 실사용 전 테스트가 필요합니다.

## v3.5 실제 학교생활기록부 PDF 검증 및 인식 개선
- NEIS 표의 분리된 '석차' / '등급' 머리글, 학기를 표시하는 병합 셀, 페이지에 이어지는 과목 행을 처리합니다.
- 과목명이 두 줄에 걸쳐 출력된 경우 같은 표 셀의 글자를 합칩니다.
- 실제 12쪽 학생부 표본의 등급 기재 교과 21과목(1-1: 7개, 1-2: 6개, 2-1: 8개)을 확인했습니다.
- 본 배포 파일에는 학생 개인정보 또는 검증에 사용한 PDF를 포함하지 않았습니다.
- 실제 학생부 양식의 다양성 때문에 자동 추출 결과는 반드시 교사가 원본과 대조해야 합니다.

## v3.6 학생부 PDF 선택 이용·대학 찾기 자동 연결
- 학생부 성적 분석 화면 첫머리에 PDF가 있을 때 이용하는 선택 기능임을 선명하게 안내합니다. PDF 없는 대학 찾기는 영향받지 않습니다.
- PDF에서 석차등급 있는 과목의 전과목 학점 가중평균을 계산하면, **5등급제**인 경우 대학 찾기의 5등급제 평균을 자동 갱신합니다. 교사 검토 전 값은 잠정값으로 표시합니다.
- 대학 찾기에서 직접 수정한 값은 뒤이은 PDF 과목 편집이 덮어쓰지 않습니다. 교사가 검토한 평균을 다시 적용하려면 명시적 적용 버튼을 사용할 수 있습니다.
- 9등급제 학생부 성적은 5등급제 자동 입력 대상이 아니며, 기존 수동 적용 버튼을 이용할 수 있습니다.
- 전체 평균은 1학년 1학기부터 3학년 1학기까지의 **석차등급이 기재된 과목**에 한정됩니다. 대학별 공식 환산등급이 아닙니다.
