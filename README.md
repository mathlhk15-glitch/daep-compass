# 대입 나침반 v4.8 — 탐색 필터 및 학교 사례 안내 정비

## 수정 내용
- 상향·적정만 체크 시, 비교 불가에 속하는 학생부종합·논술·실기와 교과 컷 결측 기록이 나오지 않게 수정했습니다.
- 「비교 불가·종합·논술·실기」를 별도로 체크하면 해당 결과를 포함합니다. 상단 전형 선택과 하단 탐색 구간은 **둘 다 만족해야** 결과에 나옵니다.
- 성적 없이 둘러보기에서는 성적 구간을 적용하지 않습니다.
- 학교 사례 탭에는 두 학교 복수 선택 및 두 가지 검색이 구현되어 있습니다. 다만 공개용 배포본에는 실제 합불 집계가 포함되지 않습니다. 파일이 없는 상태를 고장으로 오해하지 않도록 표시를 강화했습니다.
- 학교별 개인 원서·합불 원본을 공개 GitHub에 업로드하지 마세요. 학교 검토 집계라도 독립학생수·재식별 가능성·공개 승인 절차가 별도로 필요합니다.

## 배포
- ZIP 최상위 파일을 기존 GitHub Pages 저장소 루트에 업로드하세요.
- 과거에 배포한 data/school-explore.json, data/school-summary.json은 ZIP에 포함되지 않으며 저장소에서 별도 삭제해야 합니다. 공개 이력도 검토하세요.
- 전국 입시결과 2021~2026, 기존 PDF 분석 및 관심 대학 비교 기능은 유지했습니다.

## 검증 범위
- 문법 검사와 필터 조합 로직 및 ZIP 무결성을 검증했습니다. 실제 개인 자료 및 공개 GitHub Pages/모바일 사용 환경의 통합 검증은 별도입니다.
