# 대입 나침반 v3.4 — 학부모 탐색 + 교사 성적 분석(시범)

- 2021~2026 입시결과 데이터 108,596건 유지. 대학별 공식 환산·합격판정 도구가 아닙니다.
- 학생부 PDF 자동 분석은 **시범 기능**입니다. 원본 표 형식에 따라 누락/오인식이 가능하므로 원본 행 전체를 대조하세요. 실제 NEIS 학생부 PDF 표본 검증은 아직 완료되지 않았습니다.
- 계산에 포함되는 학기는 1-1, 1-2, 2-1, 2-2, 3-1이며 3-2는 항상 제외합니다. 석차등급이 있는 과목만 학점 가중평균에 사용합니다.
- 입력 PDF는 브라우저 내에서 읽고 학생부 데이터를 서버로 전송하지 않지만, PDF 해석용 라이브러리는 외부 CDN 로드가 필요합니다.
- 스캔 PDF는 OCR 미지원입니다. 자동 인식 보류 목록에 나온 항목과 추출되지 않은 원본 과목은 직접 대조하고 입력해야 합니다.
- 공개 배포 전 입시 원자료 저작권/재배포 권한을 확인하세요.

## v3.4 변경
- NEIS 텍스트 PDF의 머리글 및 x좌표를 고려한 PDF 추출/보류행 표시와 페이지 번호 기록.
- PDF.js 4.10.38 보안 수정 버전(legacy UMD인 3.x 대신 모듈)으로 교체, `isEvalSupported:false` 설정. 외부 CDN 연결 불가 시 수동 입력 가능.
- 자동 교과군 추정 + 수동 교과군 수정, 반영 제외, 학점 기준 0 초과 ~ 30 이하 통일.
- 새 업로드/초기화 작업 토큰, 원본 표시, 즉시 검토 해제, 실패 시 기존 기록 유지.
- 검토 상태/등급 체계/기간이 포함된 인쇄 표시, 검토 평균의 대학 검색 적용 버튼.
- 교과 가까운 입결 필터 문구 수정, 2021/논술 원자료 한계 표시, 데이터 이상기록 비교 강조 보류, 정렬 조정.

※ 실제 학생부 예시 2~3건으로 추출 건수·학점·등급을 검증하지 않은 상태입니다. 실사용 전 테스트가 필요합니다.
