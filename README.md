# 대입 나침반 v4.4 — 공개 배포 안전성·기능 개선

2026-10-16 기준. 전국 대학 입결 데이터 2021~2026학년도 108,596건 유지.

## v4.4 수정
- 상향·적정 필터는 교과 비교에만 적용; 학생부종합/논술/실기는 전형을 선택한 경우 항상 표시. 성적 없이 둘러보기 정상화.
- 상세 보기의 데이터 점검 기록도 성적 비교 해석 보류.
- 대학군 이름 별칭 및 일부 캠퍼스 분리 보완.
- PDF 학년 혼재 페이지의 상태 처리 및 단위수(9등급제) 머리글 인식 보완.
- 학생부 과목군 수동 지정 유지, 검토 후 선택 과목군 적용값 자동 덮어쓰기 방지, 검토 전 자동 입력 중단.
- 공개 사이트에서 구 학교 집계 JSON 삭제. 지원 건수 10건은 서로 다른 학생 10명이 아니므로 개인 재식별 위험을 완전히 배제할 수 없습니다. 원본에는 학생 고유 식별 열이 확인되지 않아 재집계·공개 보류.

## 배포 주의
ZIP 파일은 공개 GitHub Pages에 배포할 수 있도록 학교별 합불 집계를 제외했습니다. 예전에 올린 data/school-explore.json, data/school-summary.json은 GitHub 저장소에서 **직접 삭제해야** 공개 접근을 중단할 수 있습니다. 새 파일 업로드만으로 기존 파일이 삭제되지는 않습니다. Git 기록(커밋 내역)에도 과거 자료가 남을 수 있으므로 관리자와 별도로 확인하세요.

PDF 자동 인식은 서식별 편차가 있으므로 교사가 원본과 과목·학점·등급을 대조 후에만 사용해야 합니다. 5등급제와 9등급제 성적은 그대로 섞어 계산하지 않습니다.
