# 대입 나침반 학부모용 v2.8 — 자동 전체 결과 · 비교 안내 강조

## v2.8 변경 사항
- 「결과 더 보기」 버튼 제거. 검색 결과를 아래로 스크롤하면 남은 결과를 끝까지 자동으로 추가 표시합니다. 수천~수만 건을 한꺼번에 화면에 생성하지 않아 기기 부담을 줄입니다.
- 결과의 전체 건수와 현재 표시 건수를 유지합니다. 마지막 기록까지 내리면 모든 결과 확인 문구가 표시됩니다.
- 내신 비교 상태의 대비 강화: 앞섬(선명한 파랑), 비슷(노랑), 차이 있음(분홍·빨강). 테두리·굵은 왼쪽 선 추가.
- 관심 저장 및 6장 선택 시 화면이 맨 위로 돌아가지 않도록 기존 결과 카드를 유지하고 버튼 표시만 갱신합니다.
- 지원 가능성 또는 합격 확률을 보장하지 않습니다. 통계적 5→9등급 환산과 과거 컷의 참고 비교입니다.

# 대입 나침반 학부모용 v2.7 — 우선 탐색 대학 강조

## 핵심 변경
- 내신 입력 후 학생부교과전형에서 과거 70% 컷 대비 수치상 앞서거나 비슷한 기록을 결과 목록 최상단에 따로 묶어 표시합니다.
- 검색 결과 상단에서 **전체 결과 / ★ 우선 탐색 / 그 외 결과**를 선택할 수 있습니다. 모든 전형 카드의 고유 색상과 상세 입결 분석을 유지합니다.
- 우선 탐색 건수는 **대학 수나 합격 가능 대학 수가 아니라 입결 기록 건수**입니다. 같은 대학·학과의 전형 기록이 여럿 포함될 수 있습니다.
- 교과전형 이외의 종합·논술·실기는 내신 수치만으로 지원 가능 여부를 판정하지 않습니다.
- 5등급제는 강석허브 통계 대응표의 추정 9등급을 이용하며, 변환 오차와 대학별 교과 반영 차이 때문에 실제 합격 가능성과는 다릅니다.

# 대입 나침반 학부모용 v2.7 — 환산등급 비교 강화

## 이번 변경
- 자녀의 5등급제 평균을 입력하면 상단에 추정 9등급제 참고값을 크게 표시합니다.
- 검색 결과 위쪽에 추정 9등급 값을 반복 표시하여 스크롤 중에도 비교 기준을 놓치지 않게 했습니다.
- **학생부교과 카드**에서 내 아이 추정 9등급과 대학의 과거 70% 컷을 나란히 표시합니다. 카드의 강조는 과거 입결과의 숫자상 비교일 뿐 합격 가능 판정이 아닙니다.
- 종합·논술·실기 등은 내신 평균만으로 지원 가능성을 판단하지 않습니다.
- 9등급제 직접 입력 및 성적 없이 탐색도 가능합니다.

## 5등급 변환의 근거
경기·부산·광주 대응표 원자료: https://github.com/kangseok-hub/converter/blob/main/src/data/conversionData.ts
변환 알고리즘: https://github.com/kangseok-hub/converter/blob/main/src/lib/admissionUtils.ts
웹사이트: https://kangseok-hub.github.io/converter/
대응표 구간 선형 보간, '3지역 평균' 선택 시 지역별 결과의 산술평균을 사용합니다. **공식 등급 환산 방식이 아닌 통계적 추정**입니다.

## 사용 방법
`index.html`, `app.js`, `conversion.js`, `data/`를 같은 웹 서버 경로에 올려 실행합니다. HTML 파일 단독 더블클릭은 fetch가 차단될 수 있습니다.
