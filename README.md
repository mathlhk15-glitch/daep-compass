# 대입 나침반 v5.2 — 전국 입결 + 경일고·경일여고 선배 지원 기록

2021~2026 전국 수시 입시결과, 2024~2026 경일고·경일여고 선배 수시 지원 기록, 학생부 PDF 성적 분석을 한 화면에서 비교하는 참고용 웹앱입니다. 합격 가능성 판정 도구가 아닙니다.

## 배포본 두 가지
| 배포본 | 선배 기록 | 용도 |
|---|---|---|
| **교내용** | `data/school-records.csv` 포함 → 바로 표시 | 교내 상담. 학교 승인 없이 공개 인터넷 주소에 올리지 마세요 |
| **공개용** | 미포함 → 교사가 기록 CSV를 직접 불러올 때만 표시 | 공개 GitHub Pages |

두 배포본의 코드는 같습니다. 교내용 index.html에만 `<meta name="compass-school-data" content="on">` 표시가 있어서 기록 파일을 자동으로 읽습니다.
공개용 사이트에서 교사가 `school-records.csv`를 직접 불러오면 같은 화면을 볼 수 있습니다. 파일은 그 브라우저 안에서만 쓰이고, 다른 사람에게는 보이지 않습니다.

## v5.2 변경 사항
### 선배 기록: 원서 한 건 단위 (4,288건)
- 연도, 학교, 대학, 모집단위, 전형(교과/종합/논술/실기·기타)과 전형명
- 전교과·국영수사과 내신
- 결과(최초합격/충원합격/불합격), 예비순위, 불합격 사유(최저미충족·1단계 불합격·미응시)
- 1단계 결과, 모집인원, 수능최저 내용
- **넣지 않은 정보:** 이름·학번(원자료에도 없음), 한 학생의 여러 원서를 묶을 수 있는 정보, 수능·과목별 점수
- 내신은 소수 첫째 자리로 표시합니다. 두 자리까지 보이면 같은 학생의 원서가 숫자로 연결됩니다.
- 기록은 대학·학과 순으로 정렬해 원본의 학생별 순서를 없앴습니다.

### 보기 방식
- **대학·학과별 요약 (기본):** 대학 × 모집단위 × 전형별 카드. 교과와 종합은 따로 나옵니다.
  - 최초합격·충원합격·불합격(최저미충족) 건수
  - 지원 내신 범위, 합격 내신 범위, 연도, 학교별 건수
  - 카드를 누르면 건별 기록이 펼쳐집니다.
- **건별 목록:** 표 형식 (휴대폰에서는 카드형)
- 「내 성적 ±범위만 보기」를 끄면 그 학과에 지원한 내신 전체를 볼 수 있습니다.
- 내신 기준은 전교과와 국영수사과 중에서 고릅니다.
- 결과는 최초합격·충원합격·불합격 중 여러 개를 골라 걸러 볼 수 있습니다.
- 정렬: 내 성적과 가까운 순(성적이 없으면 기록 많은 순) / 최근 연도 / 내신 좋은 순 / 이름순
- 전국 입결 카드의 「🏫 우리 학교 선배 사례 보기」에는 같은 대학·학과·전형의 선배 기록(연도·내신·결과)이 나옵니다.
- 검색어(예: 「전기」, 「부산대 간호」), 관심 전형, 분야 선택, 성적은 전국 입결과 선배 기록에 똑같이 적용됩니다.

### 이전 버전에서 이어지는 수정
- 남는 `</div>` 때문에 다른 탭에도 전국 카드가 보이던 구조 오류를 수정
- 「입시자료 선택」 버튼 3가지(전국 입결 / 선배 사례 / 비교)로 통합
- 학과 매칭 엄격화(물리학과≠물리치료학과), 분교 구분(세종·ERICA 등)
- CP949·UTF-8 CSV 모두 인식

## 기록 CSV 형식
- 필수 열: `학교,연도,대학,모집단위,전형,전교과,결과`
- 선택 열: `전형명,계열,국영수사과,불합격사유,예비순위,1단계,모집인원,수능최저`
- 이름·성명·학번·연락처 열이 있으면 파일을 불러오지 않습니다.
